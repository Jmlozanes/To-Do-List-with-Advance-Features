# 🚀 TaskFlow - Advanced To-Do List Application


## 📌 Overview

TaskFlow is a modern and responsive task management application built using HTML, CSS, and JavaScript.

The application helps users organize daily tasks, track progress, manage priorities, and improve productivity through a clean and user-friendly interface.


## ✨ Features


### Task Management

✅ Create tasks  
✅ Edit tasks  
✅ Delete tasks  
✅ Mark tasks as completed  


### Productivity Features

✅ Task priority levels

- High
- Medium
- Low


✅ Due date tracking  
✅ Search tasks  
✅ Filter tasks

- All Tasks
- Active Tasks
- Completed Tasks


### User Experience

✅ Dark / Light mode toggle  
✅ Responsive design for desktop and mobile  
✅ Task statistics dashboard  
✅ LocalStorage data saving  
✅ Confirmation before deleting tasks  
✅ Empty task state message
